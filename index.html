    BEHIND THE CURVE

    What changes the shape?

    These explanations describe ax² + bx + c. Other families use a, b, c exactly as shown in their expressions.

    a — বাঁকের ধরন a ধনাত্মক হলে ওপরের দিকে, ঋণাত্মক হলে নিচের দিকে খোলে। |a| বাড়লে বাঁক সরু হয়। a = 0 হলে সরলরেখা হয়।

    b — ঢাল ও শীর্ষের অবস্থান b বদলালে ঢাল ও শীর্ষবিন্দুর অবস্থান বদলায়। a ≠ 0 হলে শীর্ষের x = −b / (2a)।

    c — ওপর–নিচে সরানো c বাড়ালে গ্রাফ ওপরে, কমালে নিচে সরে। y-axis-কে গ্রাফ (0, c) বিন্দুতে ছেদ করে। a ও b দুটোই 0 হলে y = c একটি সমান্তরাল রেখা।
